## 1. Вспоминаем основу программы

Откройте проект с предыдущего занятия. При работе через Cargo исходный код находится в src/main.rs, а команда `cargo run` собирает и запускает проект. Каждый законченный пример из конспекта можно выполнить отдельно: замените содержимое файла и запустите программу заново.

Запись `fn main()` задаёт главную функцию. В её фигурных скобках находятся выполняемые инструкции. Слово `let` создаёт переменную, а `println!()` выводит сообщение на экран. Восклицательный знак входит в имя макроса println!. В тексте сообщения `{}` обозначает место для значения, указанного после запятой.

```rust
fn main() {
    let lessons = 2;
    println!("Занятие по Rust: {}", lessons);
}
```

Программа выведет «Занятие по Rust: 2». Число 2 — значение, lessons — имя, через которое мы к нему обращаемся. Теперь рассмотрим ещё одну характеристику переменной: тип её значения.

## 2. Типы данных

Тип данных определяет, какие значения допустимы и какие действия с ними можно выполнять. Для количества студентов подходит целое число. Для средней температуры может понадобиться дробная часть. Ответ на вопрос «открыта ли дверь?» удобно хранить как логическое значение.

Rust использует статическую типизацию: типы должны быть известны компилятору до запуска программы. Компилятор проверяет исходный текст и создаёт исполняемую программу. Он также обнаруживает многие ошибки в использовании значений, например попытку сложить явно заданные несовместимые числовые типы.

Тип можно записать после имени переменной через двоеточие: `let count: i32 = 12;`. Прочитайте: «создать count типа i32 со значением 12». Когда информации достаточно, Rust определяет тип автоматически: в простом примере `let count = 12;` получится i32. Это называется выводом типа.

### Целые числа

Целые числа используются для значений без дробной части: количества, номера, разницы, суммы в выбранных целых единицах. В Rust существует несколько целочисленных типов. Они различаются допустимостью отрицательных значений и размером.

Буква i в названии обозначает целый тип со знаком: допускаются отрицательные числа. Буква u обозначает тип без знака: значения начинаются с нуля. Число в названии указывает размер в битах. Бит принимает значение 0 или 1; несколько бит позволяют закодировать множество разных чисел.

| Тип | Размер | Что важно для выбора |
| --- | --- | --- |
| `i32` | 32 бита | Целые числа со знаком; основной тип наших примеров |
| `u32` | 32 бита | Целые числа от 0 до 4 294 967 295 |
| `u8` | 8 бит | Целые числа от 0 до 255 |
| `i64` | 64 бита | Более широкий диапазон целых чисел со знаком |

У i32 диапазон от −2 147 483 648 до 2 147 483 647. Указание типа связано с границами возможных значений. Например, количество студентов можно хранить в u32, а изменение количества — в i32, поскольку изменение может быть отрицательным. Размер и диапазон важны и для промежуточных результатов вычислений.

```rust
fn main() {
    let students: u32 = 18;
    let temperature: i32 = -7;
    let brightness: u8 = 200;
    println!("Студентов: {}", students);
    println!("Температура: {}", temperature);
    println!("Яркость: {}", brightness);
}
```

Программа выведет 18, −7 и 200 с подписями. Каждое значение входит в диапазон своего типа. Запись `let brightness: u8 = 300;` вызовет ошибку компиляции: число 300 выходит за границы u8. Аналогично отрицательное число не подходит для u32.

Важно! Переполнение возникает, когда результат операции выходит за диапазон типа. При выборе типа учитывайте и исходные данные, и возможный результат. Для сегодняшних небольших чисел i32 подходит; при работе с большими значениями нужны подходящий диапазон и проверка вычислений.

В Rust есть и другие целочисленные типы: например, i8, i16, u64. Названия isize и usize связаны с разрядностью целевой платформы. С usize вы встретитесь при работе с размерами и индексами коллекций. Сейчас достаточно уверенно читать обозначения i32, u32 и u8.

### Числа с дробной частью

Для дробных значений используются `f32` и `f64`. Это числа с плавающей точкой. f32 занимает 32 бита, f64 — 64 бита и даёт большую точность представления. В обычном примере без дополнительных требований запись `let height = 1.75;` получит тип f64.

Дробная часть в исходном коде отделяется точкой. Примеры: 1.75, 36.6, 5.0. Последняя запись тоже обозначает дробное число, хотя его математическое значение целое.

Такие типы подходят для измерений, средних значений и процентов. Многие десятичные дроби хранятся приближённо. В денежных задачах с копейками удобно выбирать целую единицу — копейку — и выполнять расчёт в ней. В итоговой задаче этого занятия цены заданы целыми рублями.

### Логические значения символы и текст

Тип `bool` имеет два значения: `true` — истина и `false` — ложь. Например, has_card может хранить признак наличия карты. Позже результат сравнения двух чисел тоже будет значением bool.

Тип `char` хранит одно скалярное значение Unicode. Unicode — система кодов для символов разных языков. Для наших примеров char удобно представлять как отдельную обычную букву, цифру или знак. Некоторые сложные видимые символы состоят из нескольких значений Unicode.

Значение char записывается в одинарных кавычках: 'А', '7', '?'. Текст в двойных кавычках, например "Привет", является строковым литералом и имеет тип &str. Литерал — значение, записанное непосредственно в коде. У строк в Rust есть отдельные правила, которые подробно изучим позже; сегодня используем готовый текст в сообщениях и простых переменных.

```rust
fn main() {
    let average: f64 = 4.5;
    let has_card: bool = true;
    let answer: char = 'y';
    let message: &str = "Добро пожаловать";
    println!("Средний балл: {}", average);
    println!("Есть карта: {}", has_card);
    println!("Ответ: {}", answer);
    println!("Сообщение: {}", message);
}
```

В выводе появятся 4.5, true, y и текст приветствия. Обратите внимание: '7' — символ, 7 — число, "7" — строковый литерал. Кавычки влияют на смысл записи. Для вычисления суммы выбирайте числовые значения; для текста сообщения используйте двойные кавычки.

## 3. Операции и выражения

Выражение — запись, при вычислении которой получается значение. Например, `10 + 5` даёт 15, `price * quantity` даёт стоимость, а `age >= 14` даст логический ответ. Результат выражения можно сохранить в переменной или использовать дальше.

В арифметическом выражении значения по сторонам знака операции называются операндами. В выражении 17 + 5 операнды — 17 и 5, оператор — знак +.

| Оператор | Действие | Пример | Результат |
| --- | --- | --- | --- |
| `+` | Сложение | `17 + 5` | 22 |
| `-` | Вычитание | `17 - 5` | 12 |
| `*` | Умножение | `17 * 5` | 85 |
| `/` | Деление целых | `17 / 5` | 3 |
| `%` | Остаток от деления | `17 % 5` | 2 |

### Целое и дробное деление

Если делятся два целых числа, результат деления тоже целый. Дробная часть отбрасывается в направлении нуля. Для положительных чисел это количество полных вхождений делителя. В 17 помещаются три полные пятёрки, а остаток равен 2: 17 = 3 × 5 + 2.

```rust
fn main() {
    let whole = 17 / 5;
    let remainder = 17 % 5;
    let fractional = 17.0 / 5.0;
    println!("Целое деление: {}", whole);
    println!("Остаток: {}", remainder);
    println!("Дробное деление: {}", fractional);
}
```

Результаты — 3, 2 и 3.4. Операция % пригодится для проверки чётности: у чётного числа остаток от деления на 2 равен нулю. Деление на 100 и остаток от деления на 100 позволяют выделить рубли и копейки из целой суммы копеек.

В наших целочисленных операциях / и % делитель должен быть ненулевым. Если делитель поступает из исходных данных, это требование нужно учитывать в алгоритме. Для отрицательных целых чисел правило деления направлено к нулю: −17 / 5 даёт −3.

### Порядок действий

Умножение, деление и остаток имеют приоритет перед сложением и вычитанием. Поэтому `2 + 3 * 4` даёт 14. Скобки меняют порядок: `(2 + 3) * 4` даёт 20. Операции одного такого уровня выполняются слева направо: `20 / 5 * 2` даёт 8.

Скобки также помогают выразить смысл задачи. Формула `price * quantity + delivery` прибавляет одну доставку к стоимости всех товаров. Формула `(price + delivery) * quantity` прибавляет доставку к цене каждой единицы. Перед набором формулы назовите, что именно вычисляете.

### Изменение значения

Для изменения существующей переменной используется присваивание. Слева записывается имя, справа — новое значение или выражение. Чтобы такое изменение было разрешено, при создании переменной добавляют `mut`:

```rust
fn main() {
    let mut total: i32 = 100;
    total = total + 50;
    total += 20;
    total -= 30;
    println!("Итог: {}", total);
}
```

Последовательно получатся значения 100, 150, 170 и 140. Запись `total += 20` увеличивает текущее значение на 20. Аналогично -= уменьшает, *= умножает, /= делит, %= сохраняет остаток. В сегодняшних числовых примерах это сокращённые формы соответствующих присваиваний.

При обычном присваивании тип переменной сохраняется. Переменная total типа i32 продолжает хранить i32. Если при новом объявлении снова написать let с тем же именем, будет создано новое связывание; это называется затенением. Сегодня изменение накопленной суммы показываем через let mut и присваивание.

### Явное преобразование типов

Для выполнения числовых операций типы значений нужно согласовать. Например, переменные с явно указанными i32 и f64 нельзя непосредственно сложить обычным знаком +. Если по смыслу нужен дробный результат, целое значение можно явно преобразовать с помощью `as`.

```rust
fn main() {
    let total: i32 = 17;
    let count: i32 = 5;
    let average = (total as f64) / (count as f64);
    let late = (total / count) as f64;
    println!("Среднее значение: {}", average);
    println!("После целого деления: {}", late);
}
```

В average получится 3.4: сначала оба значения преобразуются в f64, затем выполняется дробное деление. В late сначала произойдёт целое деление 17 / 5 = 3. Полученное число преобразуется в f64, а обычный вывод покажет 3. К моменту преобразования дробная часть уже отброшена.

Слово as создаёт преобразованное значение; исходные total и count сохраняют свои целые типы. В нашем примере числа небольшие, и преобразование i32 в f64 подходит. В общем случае при преобразовании типов учитывают возможную потерю точности и допустимый диапазон.

## 4. Сравнения и условия

Сравнение проверяет отношение между значениями и даёт результат типа bool. Этот результат можно сохранить в переменной: `let is_adult = age >= 18;`. Если age равно 20, в is_adult получится true. Если age равно 16, получится false.

| Оператор | Как прочитать | Пример с результатом true |
| --- | --- | --- |
| `>` | Больше | `8 > 5` |
| `<` | Меньше | `3 < 5` |
| `>=` | Больше или равно | `5 >= 5` |
| `<=` | Меньше или равно | `3 <= 5` |
| `==` | Равно ли | `5 == 5` |
| `!=` | Различаются ли | `4 != 5` |

Один знак = используется при присваивании значения. Два знака == задают вопрос о равенстве. В строке `let is_zero = number == 0;` сначала сравниваются number и 0, затем полученный логический ответ сохраняется в is_zero.

### Конструкция if и ветвь else

Условие позволяет выполнить действие при выполнении определённого требования. Например, по температуре нужно выбрать сообщение об одежде. Для этого используется `if`:

```rust
fn main() {
    let temperature: i32 = -3;
    if temperature < 0 {
        println!("На улице мороз. Наденьте тёплую куртку.");
    } else {
        println!("Температура не ниже нуля.");
    }
    println!("Проверка температуры завершена.");
}
```

После if записано условие temperature < 0. Для −3 оно истинно. Поэтому выполняется блок в первых фигурных скобках. Слово `else` задаёт действия для случая, когда условие ложно. В этой конструкции выбирается одна из двух ветвей.

При исходной температуре вы увидите сообщение о морозе и сообщение о завершении проверки. Последняя команда println! находится после всей условной конструкции и выполняется после выбранной ветви. Если temperature изменить на 5, первая строка вывода изменится, а сообщение о завершении появится снова.

Ветвь else можно опустить. Тогда при false программа пропустит блок if и продолжит выполнение. Фигурные скобки обязательны и при одной инструкции внутри ветви. Круглые скобки вокруг простого условия в Rust обычно не записывают.

Важно! После if требуется значение bool. Запись `if 5` вызовет ошибку типов. Сформулируйте проверку явно: например, `if number > 0`. Также можно использовать готовую логическую переменную: `if has_card`.

### Несколько случаев через else if

Иногда нужно выбрать один из нескольких вариантов. Число может быть положительным, отрицательным или равным нулю. Свяжем проверки в цепочку с помощью `else if`:

```rust
fn main() {
    let number: i32 = 0;
    if number > 0 {
        println!("Число положительное.");
    } else if number < 0 {
        println!("Число отрицательное.");
    } else {
        println!("Число равно нулю.");
    }
}
```

Проверки идут сверху вниз. Сначала проверяется number > 0. Если ответ false, выполняется следующая проверка number < 0. Когда и она даёт false, программа переходит к else. Для числа 0 вы увидите «Число равно нулю».

В цепочке выполняется первая ветвь, чьё условие истинно. После её выполнения остальные проверки этой цепочки пропускаются. Отдельные конструкции if проверялись бы каждая самостоятельно. Выбирая структуру, сначала определите, должны ли действия относиться к одному общему выбору.

Порядок условий имеет значение. Например, если от 90 баллов нужен ответ «Отлично», а от 70 — «Хорошо», проверку score >= 90 следует поставить первой. Число 95 подходит под обе нижние границы. Раннее условие определит, какой ответ выберет цепочка.

### if может давать значение

Условную конструкцию можно использовать справа от знака =. Тогда выбранная ветвь даёт значение, которое сохраняется в переменной:

```rust
fn main() {
    let is_student: bool = true;
    let price: i32 = if is_student { 250 } else { 350 };
    println!("Цена билета: {} руб.", price);
}
```

Для true получается цена 250, для false — 350. Значение последнего выражения блока становится результатом блока. Поэтому внутри коротких ветвей после 250 и 350 нет точек с запятой. После всей инструкции let точка с запятой стоит.

В этом случае обе ветви должны давать значения согласованного типа. Здесь обе цены имеют тип i32. Если в одной ветви написать число, а в другой строковый литерал, компилятор сообщит о несовместимых типах. Переменной price нужен определённый тип для дальнейших действий.

Ветви можно вкладывать друг в друга. Например, сначала программа проверяет правильность количества, а внутри допустимого случая — наличие денег. У каждого блока будет своя пара скобок. Переменная, созданная внутри блока, доступна в его пределах; при дальнейшей работе обращайте внимание на расположение объявлений.

## 5. Логические операции

Одно правило может содержать несколько требований. Например, для допуска на мероприятие посетителю должно быть не меньше 14 лет и у него должен быть пропуск. Сравнение возраста даёт bool, признак наличия пропуска тоже хранится в bool. Для объединения проверок используются логические операции.

Оператор `&&` означает «И»: результат true получается, когда истинны оба условия. Оператор `||` означает «ИЛИ»: достаточно хотя бы одного истинного условия. Оператор `!` меняет логическое значение на противоположное: !true даёт false, !false даёт true.

| a | b | `a && b` | `a || b` |
| --- | --- | --- | --- |
| true | true | true | true |
| true | false | false | true |
| false | true | false | true |
| false | false | false | false |

Таблица перечисляет все сочетания двух логических значений. Например, во второй строке одно требование выполнено, другое — нет. Для && итог будет false. Для || итог будет true.

```rust
fn main() {
    let age: i32 = 16;
    let has_pass: bool = true;
    let has_invitation: bool = false;
    let can_enter = age >= 14 && has_pass;
    let has_document = has_pass || has_invitation;
    println!("Есть один из документов: {}", has_document);
    println!("Пропуска нет: {}", !has_pass);
    if can_enter {
        println!("Проход разрешён.");
    } else {
        println!("Проверьте возраст и пропуск.");
    }
}
```

Возраст 16 соответствует правилу, пропуск есть, поэтому can_enter равно true. Программа выведет true для наличия одного из документов, false для отсутствия пропуска и сообщение о разрешённом проходе. Переменная has_document здесь показывает отдельный пример логического «ИЛИ»; правило прохода определено через can_enter.

Для age = 13 допуск будет запрещён даже при наличии пропуска. Для age = 16 и has_pass = false допуск тоже будет запрещён. В каждом случае можно проследить результат отдельного требования и всей операции &&.

Сравнения выполняются раньше && и ||. В сложном правиле полезно явно обозначить группы скобками. Например, `(age >= 14 && has_pass) || has_invitation` описывает допуск по двум обычным требованиям либо по приглашению. Оба основания могут быть истинны одновременно.

Операции && и || вычисляются с сокращённой проверкой. Сначала вычисляется левая часть. Для && правая часть нужна, когда слева true. Для || правая часть нужна, когда слева false. Например, проверка `count != 0 && total / count > 5` выполнит деление только при ненулевом count. Результаты самих вычислений также должны входить в допустимый диапазон типов.

## 6. Выбор по значению с помощью match

Условие if использует логический ответ. Ещё одна распространённая задача — выбрать действие по конкретному значению: номеру команды, букве ответа или коду состояния. Для такого разбора в Rust существует `match`.

После слова match записывается проверяемое значение, затем в фигурных скобках перечисляются ветви. У каждой ветви есть образец слева и результат или действие справа. Их соединяет знак `=>`.

```rust
fn main() {
    let command: i32 = 2;
    match command {
        1 => println!("Открыта справка."),
        2 => {
            println!("Выбрана покупка.");
            println!("Подготавливаем расчёт.");
        },
        0 => println!("Работа завершена."),
        _ => println!("Неизвестная команда."),
    }
}
```

Для значения 2 выбирается соответствующая ветвь и выполняются две её команды. Они объединены в блок фигурными скобками. Для значения 1 будет показана справка. Для 0 появится сообщение о завершении.

Образцы в этом примере — конкретные целые числа. Переменная command имеет тип i32, и образцы подходят к этому типу. Если бы переменная хранила char, образцы обычных символов записывались бы с одинарными кавычками: например, 'y' или 'n'.

Символ `_` обозначает любой оставшийся случай. Если command равно 7, будет выбрана последняя ветвь. Она нужна, чтобы учесть все остальные значения i32. Match должен охватывать все возможные значения проверяемого типа; компилятор проверяет это требование.

Ветви рассматриваются сверху вниз, выполняется первая подходящая. Поэтому общий образец _ размещаем последним. После выбранной ветви выполнение продолжается за всей конструкцией match. Автоматического выполнения следующих ветвей здесь нет.

В примерах ветви разделены запятыми. После вызова println! в короткой ветви match ставится запятая. Внутри блока с несколькими инструкциями команды завершаются точками с запятой. Такое оформление помогает отличать границу отдельной инструкции от границы ветви.

### Результат match можно сохранить

Match тоже является выражением. Например, по числовому коду способа получения заказа можно выбрать текст:

```rust
fn main() {
    let method: i32 = 2;
    let description = match method {
        1 => "Самовывоз",
        2 => "Доставка",
        _ => "Неизвестный способ",
    };
    println!("Способ получения: {}", description);
}
```

Для method = 2 переменная description получит текст "Доставка". Все ветви дают строковые литералы типа &str. После закрывающей скобки match стоит точка с запятой: она завершает всю инструкцию создания description.

В этом примере у каждой ветви есть результат. Если одна ветвь давала бы число, а другая текст, сохранить такой выбор в одну переменную этим способом не получилось бы: результаты должны иметь согласованный тип. Это же правило вы уже видели в выражении if.

Для сегодняшней работы достаточно конкретных числовых или символьных образцов и завершающей ветви _. Более сложные варианты сопоставления будем рассматривать по мере появления новых задач.

## 7. Как читать ошибки и проверять решение

Если программа не собирается, начните с отмеченной компилятором строки. Найдите выражение, на которое указывает сообщение, и названия ожидаемого и полученного типов. Затем проверьте ближайшие объявления переменных и расстановку знаков.

| Ситуация | Что проверить |
| --- | --- |
| Число 300 записано в u8 | Диапазон выбранного типа |
| Изменяется переменная без mut | Предусмотрено ли изменение значения |
| В if передано число | Где должна находиться проверка, дающая bool |
| В проверке равенства один знак = | Требуется ли оператор == |
| В match разобраны только 1 и 2 для i32 | Как обработаны остальные значения |
| В выражении if из ветвей получаются число и текст | Совместимы ли типы результатов |

Ошибки результата проверяются отдельными запусками. Для границы age >= 14 полезны значения 13, 14 и 15. Для проверки бюджета нужны случаи «меньше стоимости», «равно стоимости» и «больше стоимости». Для меню нужны известные команды и хотя бы одна неизвестная.

Перед запуском назовите ожидаемую ветвь и ожидаемое сообщение. После запуска сравните их с фактическим выводом. Такая проверка связывает условие с поведением программы и помогает обнаружить неверный знак сравнения или порядок ветвей.

## 8. Практическая работа Учебный магазин

Объединим изученные конструкции. У магазина есть две команды: 1 — показать условия покупки, 2 — рассчитать заказ. Для остальных команд выводится сообщение об ошибке. Одна единица товара стоит 250 рублей. При наличии карты и количестве от трёх единиц за весь заказ предоставляется скидка 50 рублей.

В общей версии количество задаём положительным, бюджет — неотрицательным. Все денежные значения выражены целыми рублями. Покупатель берёт три товара, имеет карту и бюджет 800 рублей. До запуска вычислите стоимость: 250 × 3 = 750; после скидки — 700; остаток бюджета — 100 рублей.

```rust
fn main() {
    let command: i32 = 2;
    let price: i32 = 250;
    let quantity: i32 = 3;
    let budget: i32 = 800;
    let has_card: bool = true;
    match command {
        1 => println!("С картой от 3 товаров скидка 50 руб."),
        2 => {
            let subtotal = price * quantity;
            let eligible = has_card && quantity >= 3;
            let discount = if eligible { 50 } else { 0 };
            let total = subtotal - discount;
            println!("К оплате: {} руб.", total);
            if budget >= total {
                println!("Покупка доступна.");
                println!("Остаток: {} руб.", budget - total);
            } else {
                println!("Не хватает: {} руб.", total - budget);
            }
        },
        _ => println!("Неизвестная команда."),
    }
}
```

Сначала match выбирает режим. В ветви покупки переменная subtotal хранит исходную стоимость товаров. В eligible сохраняется логический результат двух требований скидки. Выражение if выбирает скидку 50 или 0 рублей. Затем вычисляется total и отдельное условие выбирает сообщение об оплате.

Результат исходного запуска: к оплате 700 рублей, покупка доступна, остаток 100 рублей. Цена, количество и суммы имеют тип i32; признаки has_card и eligible — bool. Переменные расчёта созданы внутри ветви 2 и используются в её пределах.

### Проверка и самостоятельное изменение

Используйте программу как основу. Сначала проверьте приведённые случаи, затем измените сообщения по заданию. Для каждого запуска задавайте данные из одной строки таблицы; цена остаётся равной 250 рублям.

| Количество | Карта | Бюджет | Ожидаемый результат покупки |
| --- | --- | --- | --- |
| 2 | true | 500 | Скидка 0, к оплате 500, остаток 0 |
| 3 | true | 800 | Скидка 50, к оплате 700, остаток 100 |
| 3 | false | 700 | Скидка 0, к оплате 750, не хватает 50 |
| 4 | true | 900 | Скидка 50, к оплате 950, не хватает 50 |

Случаи с двумя и тремя товарами проверяют границу скидки. Случай без карты проверяет второе требование. Равный бюджет проверяет знак >=. После этого отдельно запустите команды 1 и 9: должны появиться справка и сообщение о неизвестной команде соответственно.

Самостоятельно замените проверку оплаты на цепочку из трёх случаев: бюджет больше стоимости — вывести остаток; бюджет равен стоимости — вывести «Денег ровно хватает»; бюджет меньше стоимости — вывести недостающую сумму. Сохраните вычисления скидки и выбор команды через match.

Для проверки своей правки используйте quantity = 3 и has_card = true, затем бюджеты 750, 700 и 650. К оплате каждый раз будет 700 рублей. Ожидаемые результаты — остаток 50 рублей, точное равенство и нехватка 50 рублей. Объясните, какие значения имеют тип bool и где именно выбирается ветвь.
