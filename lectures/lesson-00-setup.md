# Инструменты Rust и устройство проекта

Установка описана в [docs/SETUP.md](../docs/SETUP.md).

| Название | Назначение |
|---|---|
| rustup | Устанавливает и обновляет набор инструментов Rust |
| rustc | Компилирует программу Rust |
| Cargo | Создаёт проекты, проверяет, собирает, запускает и тестирует их |
| rust-analyzer | Подсказки и диагностика Rust в VS Code |
| Git | История изменений проекта |

| Файл или папка | Что хранится |
|---|---|
| Cargo.toml | Название пакета, edition и зависимости |
| Cargo.lock | Зафиксированные версии зависимостей приложения |
| src/main.rs | Начало консольной программы |
| target/ | Результаты сборки, исключённые из Git |

Из папки проекта используйте cargo check и cargo run. Для тестов есть cargo test.
Если вы в корне курса, укажите путь, например `cargo run --manifest-path practice/01-variables/Cargo.toml`.
