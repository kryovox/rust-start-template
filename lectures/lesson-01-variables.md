# Занятие 1. Структура программы и переменные

Это памятка к уже изученной теме. Программа начинает выполнение с функции main.
Тело функции находится в фигурных скобках. Инструкции выполняются последовательно.

```rust
fn main() {
    let name = "Имя Фамилия";
    let mut score = 10;
    println!("Студент: {}, результат: {}", name, score);
    score += 5;
    println!("Новый результат: {}", score);
}
```

`fn` объявляет функцию. `main` — имя главной функции. `()` содержит параметры;
в нашем main их нет. `let` создаёт переменную с начальным значением.
По умолчанию значение связанного имени менять нельзя. `mut` разрешает изменение score.
`score += 5` прибавляет 5 к текущему значению; результат становится 15.

`println!` выводит строку с переходом на новую строку. Знаки `{}` заменяются значениями
следующих аргументов в порядке их записи. Двойные кавычки задают текст строки.
Точка с запятой завершает инструкцию. `//` начинает однострочный комментарий.

Сначала программа выведет строку с результатом 10, затем с результатом 15.
При отсутствии mut изменение score вызовет ошибку компиляции. После исправления выполните cargo run снова.
На следующем занятии подробнее разбираются типы значений и операции.
