## Начало работы

1. На странице [шаблона курса](https://github.com/kryovox/rust-start-template) нажмите **Use this template → Create a new repository**.
2. Назовите свою копию `rust-start`. Впишите имя и группу в таблицу выше.
3. Установите инструменты по [инструкции](docs/SETUP.md).
4. Склонируйте свою копию: в VS Code выберите **Git: Clone** и вставьте её адрес с GitHub.
5. Откройте папку репозитория и выполните в терминале:

```powershell
cargo run --manifest-path practice/01-variables/Cargo.toml
```

Ожидаемый вывод заготовки: «Меня зовут Имя Фамилия. Мой результат: 15».
Подробный порядок работы — [docs/START.md](docs/START.md).

У каждой работы собственный `Cargo.toml`. Запускайте Cargo из папки нужной работы
или указывайте `--manifest-path` из корня. Все заготовки используют стандартную библиотеку Rust.
Папки `target/` исключены из Git. `Cargo.lock` сохраняется вместе с консольным приложением.

## Обновления

Новые материалы поступают из шаблона ежедневно по расписанию GitHub Actions и по кнопке
**Run workflow**. Условия и конспекты обновляются; существующие решения и отчёты студентов сохраняются.
После обновления на GitHub получите изменения в VS Code. Подробнее: [docs/UPDATES.md](docs/UPDATES.md).
