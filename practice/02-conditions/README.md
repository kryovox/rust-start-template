# Практика 02. Типы, операции, условия и match

Условия: [tasks.md](tasks.md). Код: [src/main.rs](src/main.rs). Отчёт: [report.md](report.md).
Откройте эту папку в VS Code. Заготовка запускается; выполните изменения из условий.

```powershell
cargo check
cargo run
```

Для занятия 3 после написания тестов также выполните `cargo test`.
Сдайте проект Cargo и заполненный отчёт. Начальный вывод заготовки указан в `tasks.md`.
