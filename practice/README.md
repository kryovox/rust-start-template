# Практические работы

Откройте `tasks.md`, допишите заготовку `src/main.rs`, запустите проект, заполните `report.md`.

| Занятие | Работа | Запуск из корня |
|---|---|---|
| 1. Структура и переменные | [01-variables](01-variables/README.md) | `cargo run --manifest-path practice/01-variables/Cargo.toml` |
| 2. Типы и ветвления | [02-conditions](02-conditions/README.md) | `cargo run --manifest-path practice/02-conditions/Cargo.toml` |
| 3. Циклы, функции, тесты | [03-loops-functions](03-loops-functions/README.md) | `cargo run --manifest-path practice/03-loops-functions/Cargo.toml` |

Каждая папка содержит самостоятельный проект Cargo. Правила сдачи: [SUBMIT.md](../docs/SUBMIT.md).
