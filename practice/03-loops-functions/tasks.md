# Анализ диапазона чисел

Заготовка содержит `is_even`, `main` и один тест чётности. При запуске выводятся граница 10
и сообщение о её чётности. Исходный тест проверяет только `is_even`; проверки новых функций вы добавляете сами.
Объяснения синтаксиса: [занятие 3](../../lectures/lesson-03-loops-functions.md).

## Вычислительные функции

Создайте `count_even_to(limit: u32) -> u32` и `sum_even_to(limit: u32) -> u64`.
Перебирайте положительные числа от 1 до limit включительно. Используйте `for`, `1..=limit`,
вызов `is_even`, счётчик и накопитель. Для суммы преобразуйте очередное число в u64.
При limit = 0 количество и сумма равны нулю. В main выведите границу, количество и сумму с подписями.

## Простые тесты

| limit | Количество | Сумма |
|---|---|---|
| 0 | 0 | 0 |
| 1 | 0 | 0 |
| 2 | 1 | 2 |
| 7 | 3 | 12 |
| 10 | 5 | 30 |

Сохраните `checks_parity`. Добавьте `handles_small_limits` для 0 и 1,
`includes_upper_boundary` для 10, `handles_odd_limit` для 7 и `handles_first_even` для 2.
Используйте `assert_eq!`. В итоге `cargo test` должен показать 5 успешных тестовых функций.

Временно замените диапазон суммы на `1..limit`: проверка 10 должна обнаружить результат 20.
Верните включённую границу и убедитесь, что все тесты снова проходят. Запишите наблюдение в отчёт.
Поясните, почему `is_even(0)` равно true, а сумма положительных чётных до нулевой границы равна 0.
