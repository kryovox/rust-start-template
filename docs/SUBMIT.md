# Как сдавать работы

| Вид работы | Папка | Файлы |
|---|---|---|
| Практика | `practice/NN-topic/` | `src/main.rs`, `Cargo.toml`, `Cargo.lock`, `report.md` |
| Домашняя работа | `homework/NN-topic/` | код проекта Cargo и заполненный `report.md` |
| Контрольная | `exams/exam-NN/` | проект и отчёт по выданному заданию |
| Теоретический тест | `exams/quiz-NN/` | результат по инструкции преподавателя |

Условия лежат в `tasks.md`. Заготовку дописывайте на месте. Отчёт `report.md` уже подготовлен:
замените пропуски своими результатами. Сохраните входные данные и вывод для каждого проверенного случая.

## Имена и команды

Папки: `01-variables`, `02-conditions`; пакет Cargo: `variables`, `conditions`.
Основная программа — `src/main.rs`. Собственные функции называйте `snake_case`, например `digit_count`.
Для новых проектов применяйте `cargo new ... --name package_name --vcs none`.

Из папки работы:

```powershell
cargo check
cargo run
cargo test
```

В занятиях 1–2 автоматические тесты ещё не обязательны. В занятии 3 добавьте тестовые функции
для требуемых случаев. Успешный `cargo test` с нулём тестов означает, что проверки ещё не написаны.

## Коммит и отправка

| Изменение | Пример сообщения |
|---|---|
| Практика 1 | `practice 01: переменные и вывод результата` |
| Практика 2 | `practice 02: три случая проверки бюджета` |
| Практика 3 | `practice 03: сумма чётных и тест границы` |
| Домашняя работа 3 | `homework 03: количество цифр с проверкой нуля` |

1. Сохраните файлы. Проверьте запуск и результаты.
2. Проверьте список изменённых файлов. `target/` исключается через `.gitignore`.
3. Если использовали ИИ, в комментарии к решению кратко укажите вопрос и взятую идею; будьте готовы объяснить код.
4. Сделайте коммит и отправьте в `main` своей копии.
5. Отправьте преподавателю ссылку на папку работы на GitHub.

Файлы `lectures/`, `materials/`, `docs/` и условия заданий ведёт преподаватель.
Правила обновления описаны в [UPDATES.md](UPDATES.md).
