# Как приходят материалы

Источник курса: [kryovox/rust-start-template](https://github.com/kryovox/rust-start-template).
В студенческих копиях workflow **Обновление материалов курса** запланирован ежедневно
на 06:00 по Москве (03:00 UTC); фактический запуск зависит от очереди GitHub Actions.
В самом шаблоне workflow завершает работу без переноса.

## Правила переноса

| Файлы | Что происходит |
|---|---|
| `lectures/`, `materials/`, `docs/`, `.github/scripts/` | Обновляются версией преподавателя |
| Индексы `practice/README.md`, `homework/README.md`, `exams/README.md` | Обновляются |
| `README.md` и `tasks.md` внутри папок выданных работ | Обновляются: это инструкции преподавателя |
| `.gitignore`, `.gitattributes`, `rust-toolchain.toml` | Обновляются |
| Ваши `src/*.rs`, Cargo.toml, Cargo.lock и report.md | Существующие файлы сохраняются; новые добавляются |
| Корневой README и существующие настройки VS Code | Сохраняются |
| `.github/workflows/` | Автоматически не переносятся |

Файлы не удаляются. Если удалить файл заготовки, при следующем обновлении он появится снова.
Собственные решения храните в проектах работ, собственные заметки — в `report.md`.
Отдельные исправления workflow преподаватель сообщает отдельно: обычный токен обновления не меняет workflow-файлы.

## Получить обновление вручную

1. В своей копии откройте **Actions**.
2. Если GitHub предлагает включить Actions в новом репозитории, включите выполнение workflow.
3. Выберите **Обновление материалов курса → Run workflow** для ветки `main`.
4. Откройте завершившийся запуск: сводка перечисляет добавленные и обновлённые файлы.
5. В VS Code сохраните и закоммитьте свои изменения, затем выполните **Pull** или **Sync Changes**.

Автоматическое обновление меняет копию на GitHub. Локальная папка получает эти коммиты после Pull.
При конфликте сохраните обе версии кода и разберите отмеченные Git участки перед новым коммитом.

Если расписание долго не срабатывает в неактивном публичном репозитории, запустите workflow вручную
и проверьте сообщение GitHub о включении расписания. Если push отклонён политикой репозитория,
откройте лог запуска и сообщите преподавателю. Workflow запрашивает `contents: write` для коммита материалов.
