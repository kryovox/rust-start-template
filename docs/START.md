# Работа со своей копией курса

Создайте репозиторий кнопкой **Use this template → Create a new repository** на странице
[rust-start-template](https://github.com/kryovox/rust-start-template). Название вашей копии — `rust-start`.
Так GitHub запоминает источник материалов для автоматического обновления.

## Открыть проект

1. Установите [Rust, VS Code и Git](SETUP.md).
2. В своей копии GitHub нажмите **Code**, скопируйте HTTPS-адрес.
3. В VS Code откройте палитру `Ctrl+Shift+P`, выберите **Git: Clone**, вставьте адрес.
4. Откройте склонированную папку. Замените имя и группу в корневом README.
5. В терминале из корня запустите `cargo run --manifest-path practice/01-variables/Cargo.toml`.

## Обычная работа на занятии

1. Получите изменения: **Source Control → … → Pull**. Если есть свои изменения, сначала сделайте коммит.
2. Откройте условия `practice/NN-topic/tasks.md`.
3. Откройте папку работы через **File → Open Folder**, чтобы rust-analyzer увидел её `Cargo.toml`.
4. Из этой папки запускайте `cargo check`, `cargo run`, а для работ с тестами — `cargo test`.
5. Заполните `report.md`: исходные данные, ожидаемый и фактический результаты, ответы.
6. Проверьте **Source Control**, впишите понятное сообщение и нажмите **Commit**, затем **Sync Changes**.
7. На GitHub откройте папку работы и убедитесь, что виден последний коммит.

В общей папке курса лежат несколько независимых проектов. Открытие отдельной папки работы
помогает расширению rust-analyzer выбрать нужный проект. Из корня доступен запуск через `--manifest-path`.

## Новая самостоятельная работа

Создавайте её в папке, названной преподавателем. Например, из корня:

```powershell
cargo new homework/04-new-task --name new_task --vcs none
```

`--vcs none` оставляет весь курс в одном Git-репозитории. Дальше редактируйте `src/main.rs`.
Каждая работа сдаётся в `main`. Порядок сдачи и имена файлов: [SUBMIT.md](SUBMIT.md).
