# Добавление следующих занятий

1. Создайте конспект `lectures/lesson-NN-topic.md` и обновите `lectures/README.md`.
2. Добавьте `practice/NN-topic/README.md`, `tasks.md`, шаблон `report.md` и проект Cargo.
3. Для домашней работы используйте ту же структуру в `homework/`.
4. Обновите таблицы практики, домашних заданий и материалов.
5. Проверьте `cargo check`, `cargo run` и предусмотренные заданием тесты из каждой новой папки.
6. Сохраните изменения в `main` шаблона. Копии студентов получат их по расписанию или вручную.

Проекты независимы: корневой Cargo workspace не требуется. Для подключения новой работы студенту
достаточно открыть её папку. Существующий код проекта у студента при обновлении сохраняется;
изменённые требования размещайте в `tasks.md`. Для существенно новой заготовки создавайте новую папку.

Нумерация 1–3 соответствует новой последовательности Rust: переменные; типы/условия/match;
циклы/функции/тесты. Факт проведения каждого занятия уточняется по прогрессу группы.
Следующие материалы добавляются по мере подготовки и сохраняют содержательную линию ОП.04.

Организация папок и принцип обновления ориентированы на
[MaximBytecamp/ado-net-start-template](https://github.com/MaximBytecamp/ado-net-start-template).
Содержимое курса и проекты адаптированы для Rust.
