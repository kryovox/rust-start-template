# Academy Rust Lab · RS01

**Тема:** функции, условия, циклы и срезы. Создайте отдельную ветку практической работы по инструкции в Academy Hub.

## 1. Запуск

Из корня репозитория в терминале Codespaces:

```bash
cargo run --manifest-path academy-lab/Cargo.toml
cargo test --manifest-path academy-lab/Cargo.toml
```

Заготовка компилируется. Тест `smoke` проходит. Три теста заданий ожидают реализации функций.

## 2. Практика

Работайте в `academy-lab/src/lib.rs`, сохраняя сигнатуры функций.

| Функция | Задание | Пример |
|---|---|---|
| `sum_positive` | Сумма строго положительных элементов среза, результат `i64` | `[-3,5,0,2]` → `7` |
| `count_even` | Подсчитайте чётные элементы, включая ноль и отрицательные значения | `[-4,3,0,8]` → `3` |
| `clamp_value` | Ограничьте число диапазоном `[lower, upper]`, где `lower <= upper` | `(19,0,10)` → `10` |

Используйте циклы и условия. Затем можно сравнить своё решение с вариантом через итераторы. Проверяйте пустые срезы, отрицательные числа и границы диапазона. Тесты и workflow сохраняйте без изменений.

## 3. Сдача

```bash
git branch --show-current
git add academy-lab/src/lib.rs
git commit -m "Complete RS01"
git push
git rev-parse HEAD
```

Вставьте полный SHA коммита в Academy Hub. GitHub Actions проверит этот коммит. Завершив работу, остановите Codespace в списке активных сред.
