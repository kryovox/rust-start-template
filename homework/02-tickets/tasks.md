# Билеты на выставку

Команда типа i32: 1 — показать правила, 2 — покупка, остальные — неизвестная команда.
Обычный билет стоит 400 рублей, льготный — 250; выбор задаётся has_benefit типа bool.
Количество билетов и бюджет задаются переменными i32, бюджет неотрицательный.

В ветви покупки сначала проверьте количество: при quantity <= 0 сообщите «Количество должно быть положительным».
При положительном количестве выберите цену выражением if, вычислите стоимость и обработайте
три случая: бюджет больше стоимости, равен ей, меньше её. Выводите остаток, сообщение о равенстве
или нехватку денег. Используйте match и вложенные условия.

| Случай | Ожидаемый результат |
|---|---|
| 2 льготных, бюджет 500 | К оплате 500, ровно хватает |
| 2 обычных, бюджет 500 | К оплате 800, не хватает 300 |
| 2 льготных, бюджет 700 | К оплате 500, остаток 200 |
| Количество 0, команда 2 | Сообщение о количестве |
| Команда 9 | Неизвестная команда |
| Команда 1 | Правила покупки |

Дополнительно: при успешной покупке по положительному чётному номеру билета сообщите о подарке.
Стоимость сохраняется. Сдайте программу и результаты каждого запуска в отчёте.
