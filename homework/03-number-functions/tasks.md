# Функции для чисел

## Обязательные функции

1. `sum_odd_to(limit: u32) -> u64`: сумма положительных нечётных чисел от 1 до limit включительно.
   Примените for, диапазон, условие и накопитель. Проверки: 0 → 0; 1 → 1; 5 → 9; 10 → 25.
2. `digit_count(number: u32) -> u32`: количество десятичных цифр. У числа 0 одна цифра.
   Примените while и целое деление на 10, отдельно обработайте ноль.
   Проверки: 0 → 1; 7 → 1; 10 → 2; 1000 → 4.

Для каждой функции опишите вход, результат и граничный случай. Напишите тестовые функции с #[test]
и assert_eq!, запустите cargo test. В main выведите результаты с понятными подписями через println!.
Отчёт должен содержать число тестов, вывод программы и объяснение обработки нуля.

## Дополнительная функция

`first_multiple(start: u32, end: u32, divisor: u32) -> u32` возвращает первое число включённого диапазона,
делящееся на divisor. Для задания заранее заданы start >= 1, start <= end, divisor >= 1;
подходящее число в диапазоне существует. Используйте for и ранний return.
В конце функции предусмотрите запасной результат 0, до которого выполнение при этих условиях не дойдёт.
Зафиксируйте это соглашение. Проверки: (3, 10, 4) → 4; (8, 12, 4) → 8; (9, 12, 4) → 12.
