# Проверка установки

1. Выполните [установку инструментов](../../docs/SETUP.md).
2. Запишите в report.md вывод `rustc --version`, `cargo --version` и `git --version`.
3. Откройте эту папку. Выполните `cargo check` и `cargo run`.
4. В src/main.rs задайте переменные имени и группы. Выведите строку «Привет! Меня зовут …, группа …».
5. Повторите запуск, сохраните вывод в отчёте, отправьте коммит на GitHub.

Объясните назначение Cargo.toml, src/main.rs, Cargo.lock и target/. Версии инструментов могут отличаться у разных студентов.
